# Karaoke da sogra

Fiz esse programinha para ajudar minha sogra baixar músicas novas para o karaokê dela.
Tentei extrair o máximo que pudia do Github Copilot para meio que testar quão rápido conseguimos botar na prática uma ideia.

O karaoke dela permite ela adicionar músicas novas se mover arquivos .mp4 para uma pasta específica do pendrive que armazena as músicas.
As músicas devem ter o título "<Número da Lista> - <Título da música>" e ter o número maior que os últimos da lista.

Se não cair no esquecimento, pretendo adicionar no final uma página para enviar as músicas direto pro pendrive, semelhante a página de input do arquivo com a lista de músicas.
